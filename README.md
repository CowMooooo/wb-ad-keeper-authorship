# WB Ad Keeper

Публичная фиксация происхождения и архитектуры самостоятельного программного продукта WB Ad Keeper.

WB Ad Keeper — универсальная self-hosted система сбора данных маркетплейса, анализа общей воронки и рекламы, работы с поисковыми фразами и подготовки управленческих действий по продвижению товаров.

Концептуальная основа продукта сформировалась в 2021 году, принцип совмещения трафика карточки с корзинами и заказами — в 2024 году, а самостоятельная программная реализация WB Ad Keeper началась 7 июня 2026 года. До начала применения в кабинете DEPPA в проекте уже существовали:

- собственная интеграция с API Wildberries;
- модель `кабинет → артикул → поисковая фраза → метрики → решение`;
- мониторинг рекламных кампаний и поисковых кластеров;
- классификация фраз и очередь предлагаемых действий;
- безопасный режим без автоматического изменения кабинета;
- сопоставление рекламного трафика с общими заказами;
- объединённая воронка продаж и рекламы;
- работа по одному артикулу, набору артикулов, группе и всему магазину;
- локальное хранение истории без повторной загрузки при каждом открытии;
- отдельный экран для анализа и очистки поисковых фраз.

Этот репозиторий не является открытой публикацией исходного кода и не предоставляет открытую лицензию. Он содержит публичное описание продукта, ранее созданные проектные документы, хронологию и контрольные суммы закрытых исходных материалов.
