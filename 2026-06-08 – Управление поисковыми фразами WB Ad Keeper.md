# WB Ad Keeper v0.4 — Cluster Cleaner

## Назначение

Отдельная вкладка `/cluster-cleaner` для операционной чистки рекламных поисковых кластеров Wildberries. Текущая вкладка `/overlay` не трогается.

## Логика экрана

Верхняя таблица показывает все кластеры за выбранный период. Нижняя таблица показывает кластеры, которые система считает кандидатами на минусацию, уже исключённые кластеры и actions на минусацию.

## Ключевые данные

- `norm_query` — поисковый кластер / фраза;
- `current_bid` — текущая ставка, если известна;
- `views`, `clicks`, `ctr`, `cpc`, `cpm`, `spend`, `atbs`, `orders`, `avg_pos`;
- `classification` — результат regex-классификации;
- `decision` — действие системы: оставить, целевой, защищён, кандидат в минус, проверить, уже в минусах;
- `reason` — причина решения.

## Правила

Приоритет правил:

1. `whitelist` — защищает фразу;
2. `blacklist` — кандидат в минус;
3. `no_bid` — не повышать ставку;
4. `target` — целевой кластер;
5. эвристики: 100+ показов и 0 кликов, низкий CTR и 0 корзин.

## Безопасность

`ALLOW_APPLY=false` по умолчанию. Экран не должен автоматически менять WB. Он показывает решения и proposed actions. Реальное применение остаётся отдельным шагом через executor и должно включаться только после проверки.
